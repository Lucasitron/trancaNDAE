Como funciona
  1. Ao enviar, a página grava PIN:nome em comandos/{dispositivo} (último comando vence — um por vez).
  2. O ESP32 recebe via stream, cadastra na tabela local (RAM+NVS) e apaga o nó em seguida. Renovar troca o PIN; Apagar remove uma chave; LIMPAR zera tudo.
  3. A página lê de volta só o resumo (resumo/{dispositivo}: nomes + datas, nunca o PIN). A abertura é somente no teclado, digitando o PIN + #.
