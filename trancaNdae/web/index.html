Como funciona
  1. Ao enviar, a página grava os metadados em pessoas/{dispositivo}/{nome} (nome, data, validade, status) e o comando PIN:nome em comandos/{dispositivo}.
  2. O ESP32 recebe via stream, cadastra o PIN na tabela local (RAM+NVS) e apaga o comando — o PIN não permanece no database.
  3. A página lista os metadados do Firebase e bloqueia (BLOQ) as chaves vencidas. A abertura é somente no teclado, digitando o PIN + #.
Wi-Fi do ESP (rede secundária)

O ESP usa o Wi-Fi padrão gravado nele. Aqui você configura um secundário: se o padrão falhar, ele tenta o secundário sozinho. Desativando, volta a usar só o padrão.
